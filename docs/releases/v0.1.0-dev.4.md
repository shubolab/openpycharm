PyCharm 1:1 parity remains incomplete. Both native CI jobs and independently

## English

This preview adds an independent native JavaScript and TypeScript language
service to the open-source PyCharm 2026.1.4 desktop. The packaged product now
has five independent plugins: HTTP Client, Python Frameworks, Notebooks, Database,
and JavaScript and TypeScript.

- **Native language service:** completion, diagnostics and definition navigation
  through the public IntelliJ Platform LSP API, including unsaved editor text.
  It is enabled by default for trusted local project content. Opening an
  untrusted project does not start the service.
- **Bundled tools:** Node.js 24.22.3, TypeScript 6.0.3 and
  typescript-language-server 6.1.0. All 191 pinned runtime files, corresponding
  notices and the complete tool manifest are authenticated before startup.
  Editor opening performs no runtime download or dependency installation.
- **Project settings:** enable or disable the service under
  **Languages & Frameworks → JavaScript and TypeScript**. Analysis uses
  project-scoped state under the isolated IDE system directory. Process startup
  and filesystem authentication run outside the Swing event dispatch thread.
- **Distribution:** the product assembler accepts an explicit frontend provision
  receipt and verifies the complete runtime after copying and before installer
  creation or startup. The frontend development M0 and native guardian prototype
  are not packaged. Existing Notebook, Database, HTTP and framework capabilities
  are retained.

The local dev.4 DMG candidate was actually installed on macOS 27.2 arm64 with
Python 3.14. Python Run, unittest (9 methods/20 items), breakpoint debugging,
F8 stepping, expression evaluation displaying `2.0400`, F9 resume, native Python
completion, and cross-file Rename/Undo passed. Tests passed again after Undo.
TypeScript member completion, a real type diagnostic and Cmd+B definition
navigation passed. JavaScript accepted a new member from unsaved text containing
Chinese and emoji. Normal project close removed its three owned Node processes.
The installed app tree stayed unchanged and strict signature verification passed.
These observations apply to the local DMG built from `88387c3`, SHA-256
`8b849bc6db67e929c8dff25ed32f79b0bb1d420c89487b6d85c0e34c8545dd64`.
Its 171 production source inputs match the later CI source `63921a4`; the latter
adds test/documentation changes. The local capture and CI artifact receipts
remain separate.

The linked CI run completed successfully on both platforms, including frontend
JVM/191-file runtime authentication, native product gates and DMG/EXE installer
checks. Mac ran 177 repository controls (175 passed, 2 SDK checks skipped before
the SDK was prepared); Windows ran 177 (171 passed, 6 explicit skips). Both then
passed the four frontend actual-SDK controls. The downloaded artifacts passed independent hash, CRC, path and source checks. Windows physical keyboard-and-mouse acceptance
has not been performed. Earlier dev.3 Notebook/SQLite desktop results remain
version-specific historical evidence.

Full JavaScript/TypeScript syntax PSI, syntax-aware refactorings, HTML/CSS,
frontend framework semantics and frontend debugging remain incomplete. Framework
template/ORM support, network database/TLS/authentication, unexpected owner-crash
orphan cleanup and full PyCharm 1:1 parity remain open. Notebook remote kernels,
widgets and debugging, database result editing/export and SSH tunnels remain
unimplemented.

## 简体中文

本预览版在开源 PyCharm 2026.1.4 原生桌面中，新增独立 JavaScript 和 TypeScript
语言服务。产品共包含五个自有插件：HTTP Client、Python Frameworks、Notebooks、
Database、JavaScript and TypeScript。

- **原生语言服务：** 使用 IntelliJ Platform 公开 LSP API，提供补全、诊断和定义
  跳转，并同步未保存的编辑器文本。对已信任的本地项目内容默认开启；未信任项目
  不启动语言服务。
- **随包工具：** Node.js 24.22.3、TypeScript 6.0.3 和
  typescript-language-server 6.1.0。启动前核对固定的 191 个运行时文件、相关法律
  声明和完整工具清单；打开编辑器不下载运行时、不安装依赖。
- **项目设置：** 在 **Languages & Frameworks → JavaScript and TypeScript** 中
  开关服务。分析状态按项目写入独立 IDE system 目录，文件认证和进程启动在 Swing
  事件线程之外完成。
- **发行装配：** 显式传入前端 provision 收据，复制后、生成安装器和启动前均核对
  完整运行时。开发用途的 M0 和 native guardian 原型不随产品分发；保留已有 Notebook、
  数据库、HTTP 与框架能力。

本机 dev.4 DMG 候选已实际安装于 macOS 27.2 arm64，使用 Python 3.14。Python
运行、9 个方法/20 项 unittest、断点、F8 单步、显示 `2.0400` 的表达式求值、F9
继续、原生 Python 补全、跨文件 Rename/Undo 均通过，撤销后再次运行测试通过。
TypeScript 实测成员补全、真实类型诊断和 Cmd+B 定义跳转；JavaScript 在含中文、
emoji 的未保存文本中接受新增成员补全。正常关闭项目后，三个自有 Node 进程均退出。
安装版产品树未变，严格签名核对通过。这些观察属于源码 `88387c3` 的本机 DMG，
SHA-256 为 `8b849bc6db67e929c8dff25ed32f79b0bb1d420c89487b6d85c0e34c8545dd64`。
其 171 项生产输入与后续 CI 源码 `63921a4` 相同，后者只增加测试/文档修改；本机拍摄
与 CI 产物收据分别记录。

上述 CI 已在两个平台全部成功，包括前端 JVM/191 文件认证、原生产品与 DMG/EXE
安装器检查。macOS 运行 177 项仓库控制，175 项通过、SDK 准备前跳过 2 项；Windows
运行 177 项，171 项通过、6 项明确跳过。随后两个平台均通过 4 项前端实际 SDK
控制。下载产物的摘要、CRC、路径和源码清单已独立核对。Windows 真实键鼠桌面未验收，dev.3 的 Notebook/
SQLite 桌面结果仍保留为对应历史版本证据。

JavaScript/TypeScript 完整语法 PSI、语法感知重构、HTML/CSS、前端框架语义和前端
调试仍未完成。框架模板/ORM、网络数据库/TLS/认证、进程所有者意外崩溃后的孤儿
清理和完整 PyCharm 1:1 对齐仍待实现或验收。Notebook 远程内核、widgets、调试，
数据库结果编辑/导出与 SSH 隧道尚未实现。
