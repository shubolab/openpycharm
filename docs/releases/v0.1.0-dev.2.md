## English

This preview adds native HTTP tools and independent framework project support to
the open-source PyCharm 2026.1.4 desktop foundation.

- **HTTP files and Services:** edit `.http` requests, run the current request or
  a batch, inspect responses in native Services, save the original response
  bytes, and stop active requests.
- **Django, Flask and FastAPI:** native New Project generators and dedicated
  Run/Debug configuration types reuse the selected Python interpreter/venv,
  working directory and environment. Dependency installation is optional and
  off by default. Small generated examples return a normal Hello response.
- **Cold Markdown startup:** a bounded public-source replay moves JCEF singleton
  construction out of the Holder class initializer. Markdown/JCEF, proxy
  settings and service authentication remain enabled. The final installed
  README restoration check is still pending.

These templates and native launch/debug configurations are not complete
framework semantic support. Framework template/ORM intelligence and broader
navigation remain pending. HTTP environment files, OAuth and broader credential
flows are outside this slice. **Notebook and database tools are not in dev.2.**
Full 1:1 parity is not verified.

Final macOS installed Run, unittest, FastAPI Debug, HTTP, cold README restoration
and the versioned demo GIF are pending. Earlier development-app and rejected
installer observations are recorded separately in the verification draft.
Windows interactive desktop workflows remain unverified, even when native CI
installation/startup checks succeed.

Planned installers are macOS Apple silicon `.dmg` and Windows x64 `.exe`, with
SHA-256 and provenance. Their final hashes and release links are pending; use
the currently published [dev.1](https://github.com/shubolab/openpycharm/releases/tag/v0.1.0-dev.1)
for existing downloads. The Mac application is ad-hoc signed and not notarized;
the Windows installer is unsigned.

Local IDE use has no IDE account, billing, subscription, trial or upgrade-promotion
flow. Git/GitHub/private-repository and user-selected service authentication are
preserved. The reference PyCharm installation is read-only; redistribution uses
the pinned open-source release and retains upstream and third-party notices.

## 简体中文

本预览版在开源 PyCharm 2026.1.4 原生桌面基础上，新增 HTTP 工具和独立框架项目支持。

- **HTTP 文件与 Services：** 编辑 `.http` 请求，运行当前请求或批量请求，在原生
  Services 中查看响应，保存原始响应字节，并停止正在执行的请求。
- **Django、Flask、FastAPI：** 原生 New Project 生成器与专用运行/调试配置复用所选
  Python 解释器/venv、工作目录与环境变量。依赖安装可选、默认关闭；生成的小型示例
  返回普通 Hello 响应。
- **Markdown 冷启动：** 有界回放公开源码，将 JCEF 单例构造移出 Holder 类初始化。
  保留 Markdown/JCEF、代理设置和服务认证。最终安装版 README 恢复检查仍待完成。

这些模板和原生运行/调试配置不等于完整框架语义支持。框架模板/ORM 智能分析和更广
导航仍待补齐。本次 HTTP 不包含环境文件、OAuth 和更广凭据流程。
**dev.2 不包含 Notebook 和数据库工具。** 完整 1:1 对齐尚未验证。

最终 macOS 安装版的运行、unittest、FastAPI 调试、HTTP、README 冷恢复以及带版本
的演示 GIF 均待完成。较早开发版和被拒绝安装候选的观察在验收草稿中单列。即使原生
Windows CI 安装、启动检查成功，Windows 交互式桌面工作流仍未验收。

计划提供 macOS Apple silicon `.dmg` 与 Windows x64 `.exe`，同时提供 SHA-256 和
来源收据。最终摘要与发行链接待补充；当前可下载版本仍为
[dev.1](https://github.com/shubolab/openpycharm/releases/tag/v0.1.0-dev.1)。Mac 应用使用
临时签名、未经公证；Windows 安装器未签名。

本地 IDE 使用不包含 IDE 账号、计费、订阅、试用和升级推广流程；保留 Git、GitHub、
私有仓库及用户选择的服务认证。对照 PyCharm 安装保持只读；分发使用固定开源版本，
保留上游及第三方声明。
