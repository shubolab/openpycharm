## English

This preview adds independent native Notebook and Database tools to the
open-source PyCharm 2026.1.4 desktop, alongside the existing HTTP and framework plugins.

- **Notebook:** code, Markdown and raw cells; a selected local Python kernel;
  execution, interrupt and restart; source undo, asynchronous save, external-text
  merge and reopen. Native Swing previews display bounded PNG/JPEG images,
  static HTML tables and Markdown. Kernel use requires `jupyter_client==8.6.3`
  and `ipykernel==6.29.5` in the selected interpreter.
- **Database:** native connection profiles and SQL console, metadata browsing,
  managed transactions, cancellation and bounded metadata completion, including
  aliases and quoted Unicode identifiers. SQLite controls run against real
  disposable databases. PostgreSQL/MySQL drivers are included; network-server
  and PasswordSafe provider/authentication acceptance remains pending.
- **Corrections:** background Notebook saving avoids the outer write-intent lock;
  ordinary cell-add/delete callbacks acquire PSI read access; rich image reservations
  survive until the final viewer reference is released. Narrow database panes
  adapt to native tabs, and completion replaces the complete typed identifier
  while preserving current text if its metadata snapshot expires.

Both native CI jobs passed. macOS passed all 125 repository tests; Windows ran
125, passed 122 and explicitly skipped 3 POSIX controls. Both passed the 9 Python
example tests, actual JVM/kernel controls, native startup and their installer gates.
Both also passed the actual native Notebook edit/undo/merge/Save All/reopen API
gate. It creates only a generated owned project through the normal IDE new-project
lifecycle, retains parent-directory distrust and uses no global trust override.
This gate does not claim manual Trust-dialog or physical keyboard/mouse acceptance.

Windows interactive desktop workflows and forced backpressure-disposal fixtures
remain unverified. Active Notebook JavaScript/widgets, full framework semantic
support, frontend M0 and full 1:1 PyCharm parity are outside this release.

## 简体中文

本预览版在开源 PyCharm 2026.1.4 原生桌面基础上，新增独立 Notebook 与数据库工具，
保留已有 HTTP、Django、Flask、FastAPI 项目及运行/调试支持。

- **Notebook：** 支持代码、Markdown、raw 单元格，使用所选本地 Python 内核运行、
  中断和重启；支持源码撤销、异步保存、外部 JSON 修改合并及关闭重开。原生 Swing
  预览显示有界 PNG/JPEG、静态 HTML 表格与 Markdown。所选解释器需安装
  `jupyter_client==8.6.3` 和 `ipykernel==6.29.5`。
- **数据库：** 提供原生连接配置、SQL 控制台、元数据浏览、受管事务、取消及有界
  元数据补全，覆盖别名和带引号的 Unicode 标识符。SQLite 使用真实临时数据库验证。
  已包含 PostgreSQL/MySQL 驱动；网络数据库及 PasswordSafe 提供方/认证流程尚未验收。
- **修复：** Notebook 后台保存移除外层写意向锁；普通新增/删除单元格回调补齐 PSI
  读锁；富输出图像额度保留到最后一个 viewer 引用释放。数据库窄面板改用自适应原生
  标签页；补全替换完整输入标识符，并在元数据过期时保留用户最新文本。

最终双平台 CI 均成功。macOS 的 125 项仓库测试全部通过；Windows 运行 125 项，
122 项通过、3 项明确的 POSIX 控制跳过。两端各 9 项 Python 示例测试、实际 JVM/内核
控制、原生启动及安装器检查通过。原生 Notebook 编辑、撤销、合并、Save All、关闭重开
API 门也在两端通过：它仅通过正常新项目生命周期创建生成的自有项目，父目录前后均
保持不可信，不设置全局 trust 开关；未将此结果称为手工 Trust 点击或实体键鼠验收。

Windows 交互式桌面与强制背压释放夹具仍未验证。本版不包含 Notebook 活动 JavaScript/
widgets、完整框架语义支持或 frontend M0；完整 PyCharm 1:1 对齐尚未验收。
