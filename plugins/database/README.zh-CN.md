# 原生数据库插件

这是独立编写的 Apache-2.0 插件，使用固定版本的开源 IntelliJ Platform、原生编辑器、PSI、Swing 和 JDBC。没有使用专有 Database Tools 实现或 WebView。

在 **Database** 工具窗口手动添加 SQLite、PostgreSQL 或 MySQL 连接（MySQL 使用 MariaDB Connector/J）。支持连接与断开、表/视图列表、列信息、生成带标识符转义的 SELECT、结果预览、受影响行数、取消查询，以及明确的开始/提交/回滚事务。SQL 控制台使用 IntelliJ 原生编辑器；`.sql` 文件提供词法着色、基础 PSI 和右键菜单 **Run SQL Statement**。选中文本时执行选中的一条语句，否则执行光标所在语句。不会自动执行整个脚本。

项目工作区文件仅保存非敏感连接字段。密码通过 IntelliJ PasswordSafe 保存，遵循用户的内存/系统钥匙串设置。密码键绑定规范化项目路径、连接端点、用户名、连接 ID 和 TLS 设置；修改这些字段后，需要为新范围提供凭据。打开项目不会连接数据库或执行查询。无法识别的驱动名及附加元数据会保留，并保持断开状态。

JDBC、密码读取和文件操作都在后台执行。查询支持独立取消通道和 15 秒取消截止机制；连接及网络读取也有超时。预览最多显示 500 行、100 列、每格 4096 字符、总计 2 MiB 文本；二进制只预览前 64 字节。这些限制约束展示结果；驱动可能在内部缓存数据，不能据此保证驱动总内存或数据库服务端执行时间。取消依赖驱动支持。断开连接或关闭项目时，尚未提交的手动事务会回滚。

PostgreSQL/MySQL 默认校验 TLS 证书和主机名；可为本地测试服务器明确关闭校验。连接字段不接受任意 JDBC URL 或属性，不提供 URL 内嵌密码、local-infile 或多语句执行选项。完整构建命令、第三方许可证和已知边界见 [英文说明](README.md)。一次性 SQLite 示例见[数据库示例](../../fixtures/database/README.md)。

已观察到：通过认证的 macOS ARM64 SDK 编译、真实 IntelliJ 归档读取校验、临时 SQLite 查询/事务/元数据/取消/超时/关闭、原生状态序列化、凭据范围隔离和词法增量重启检查。

尚未验证：原生桌面交互与扩展注册、真实 PostgreSQL/MySQL 服务器的 TLS/认证/取消、Windows 运行时，以及复杂大型库。驱动已加载并识别生成的 URL，测试没有访问网络数据库。尚未实现数据库补全、方言语义检查、迁移、SSH 隧道、结果单元格编辑或导出；不能据此宣称完全 1:1。本次只交付源代码增量，没有发布新安装包或更新功能演示 GIF。

事务请使用工具栏的开始/提交/回滚按钮。为避免 JDBC 与界面状态不一致，控制台会拒绝直接事务控制和会话控制语句。DDL 仍遵循数据库自身的隐式提交规则。含糊的反斜杠引号会被拒绝，请用两个连续单引号转义字符串内的单引号。取消请求绑定具体查询，过期请求不会取消下一条语句。
